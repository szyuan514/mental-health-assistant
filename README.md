# AI心理陪伴助手

基于 DeepSeek API 和 Streamlit 构建的 AI 心理陪伴助手，具备情绪倾听、心理风险分级识别、危机干预等功能。

## 功能特点

- 自然对话：温暖共情的 AI 心理陪伴
- 风险分级：低/中/高三档风险识别（关键词筛查 + AI 语义判断）
- 危机干预：高风险时先共情后提供求助资源
- 学校对接：一键预约学校心理中心
- 个性化：自由选择用户和 AI 头像

## 技术栈

- Python 3.14
- Streamlit（前端框架）
- DeepSeek API（大语言模型）

## 快速开始

```bash
pip install -r requirements.txt
streamlit run app.py
